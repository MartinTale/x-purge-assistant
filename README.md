# X Purge Assistant

Chrome extension to prune your X following list.

- Popup **Import** opens your following page, auto-scrolls it and saves every account (no API; scrapes the rendered list).
- Popup interval setting opens a random non-kept account in a new tab on a schedule; Pause/Resume button, auto-pauses when nothing is left to review.
- A **Keep** button appears next to Following buttons on x.com; kept accounts are saved locally. Unfollow the rest manually.
- Follow/Unfollow state seen on x.com (rows and profiles) keeps the saved list in sync.

Load unpacked at `chrome://extensions` (Developer mode).
